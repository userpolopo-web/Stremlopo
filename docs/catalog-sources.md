Todas as URLs de vídeo responderam com HTTP 200 e suporte a requisições Range na revisão. Isso verifica disponibilidade, não substitui a licença. Imagens foram convertidas para WebP e reduzidas para uso no app; os créditos aparecem na página do filme. Sintel usa uma fonte de 1080p, que pode consumir mais dados.

As marcas dos projetos pertencem aos seus titulares; o aplicativo não afirma afiliação com a Blender Foundation. As versões em vídeo conservam o conteúdo e o crédito originais. Licenças também ficam registradas em `android/app/src/main/assets/catalog.json`.

Denúncias sobre títulos incluídos abrem um formulário de issue no GitHub para o usuário revisar e enviar; se há servidor adicional configurado, usam a API de denúncias. Sem envio automático de mensagens.
